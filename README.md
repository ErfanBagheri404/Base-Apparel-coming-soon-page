# Base Apparel coming soon page

![Design preview for the Base Apparel coming soon page challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Base Apparel coming soon page** challenge - a responsive landing page built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Base-Apparel-coming-soon-page/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Vanilla JavaScript for the interactive behaviour (no framework, no build step)
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Base-Apparel-coming-soon-page.git
cd Base-Apparel-coming-soon-page
```

Open `index.html` in a browser. Nothing to install or compile.
